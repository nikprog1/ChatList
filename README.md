# ChatList

Приложение для отправки промтов в несколько нейросетей и сравнения их ответов.

## Описание

ChatList — это Python-приложение с графическим интерфейсом, которое позволяет:
- Отправлять один и тот же промт в несколько нейросетей одновременно
- Сравнивать ответы разных моделей в удобной таблице
- Сохранять результаты в базу данных
- Просматривать историю сохраненных результатов
- Управлять моделями нейросетей
- Экспортировать результаты в различные форматы

## Требования

- Python 3.11+
- SQLite (встроенная библиотека)
- PyQt5 5.15.10+
- httpx 0.25.2+
- python-dotenv 1.0.0+

## Установка

1. Клонируйте репозиторий или скачайте проект:
```powershell
cd C:\Work\ChatList
```

2. Установите зависимости:
```powershell
pip install -r requirements.txt
```

3. Создайте файл с переменными окружения:

**Рекомендуется использовать `.env.local`** (не коммитится в git) или `.env`:

```powershell
# Создайте файл .env.local для локальных настроек
notepad .env.local
```

Добавьте ваши API-ключи:
```
OPENROUTER_API_KEY=your_openrouter_api_key_here
OPENAI_API_KEY=your_openai_api_key_here
DEEPSEEK_API_KEY=your_deepseek_api_key_here
GROQ_API_KEY=your_groq_api_key_here
```

**Приоритет загрузки:** `.env.local` → `.env` → системные переменные окружения

## Использование

### Запуск приложения

#### Способ 1: Прямой запуск из PowerShell

Откройте PowerShell в папке проекта и выполните:

```powershell
# Перейдите в папку проекта (если еще не там)
cd C:\Work\ChatList

# Запустите приложение
python main.py
```

#### Способ 2: Запуск с явным указанием Python

Если `python` не найден, используйте полный путь или `py`:

```powershell
# Использование py launcher (рекомендуется для Windows)
py main.py

# Или с указанием версии Python
py -3.11 main.py
```

#### Способ 3: Запуск через pythonw (без консоли)

Для запуска без окна консоли (только GUI):

```powershell
pythonw main.py
```

#### Проверка перед запуском

Перед первым запуском убедитесь, что:

1. **Установлены все зависимости:**
```powershell
pip install -r requirements.txt
```

2. **Создан файл `.env.local` или `.env` с API-ключом OpenRouter:**
```powershell
# Откройте .env.local в редакторе (рекомендуется) или .env
notepad .env.local
```

**Важно:** В файле `.env.local` (или `.env`) должна быть строка с вашим реальным API-ключом:
```
OPENROUTER_API_KEY=sk-or-v1-ваш_реальный_ключ_здесь
```

**Рекомендации:**
- Используйте `.env.local` для локальной разработки (автоматически игнорируется git)
- Используйте `.env` для общих настроек команды (можно добавить пример в репозиторий)
- Приоритет: `.env.local` имеет приоритет над `.env`

⚠️ **Убедитесь, что:**
- Переменная называется именно `OPENROUTER_API_KEY` (без пробелов)
- После `=` сразу идет ваш ключ (без пробелов)
- Нет лишних пробелов или символов
- После изменения `.env` **перезапустите приложение**

3. **Проверьте, что Python установлен:**
```powershell
python --version
# Должно показать версию Python 3.11 или выше
```

#### Решение возможных проблем

**Проблема: "python не распознан как команда"**
```powershell
# Используйте py вместо python
py main.py

# Или добавьте Python в PATH
```

**Проблема: "ModuleNotFoundError"**
```powershell
# Установите зависимости
pip install -r requirements.txt

# Или установите конкретный модуль
pip install PyQt5 httpx python-dotenv
```

**Проблема: Окно не открывается**
```powershell
# Запустите с выводом ошибок
python main.py 2>&1 | Out-File -FilePath errors.log

# Или проверьте, что PyQt5 установлен
python -c "import PyQt5; print('PyQt5 OK')"
```

### Добавление моделей

1. Перейдите на вкладку "Модели"
2. Нажмите "Добавить модель"
3. Заполните форму:
   - **Название модели**: например, "gpt-4" или "claude-3-opus"
   - **API URL**: URL эндпоинта API (например, `https://api.openrouter.ai/api/v1/chat/completions`)
   - **Переменная окружения**: название переменной из файла `.env` (например, `OPENROUTER_API_KEY`)
   - **Тип провайдера**: выберите тип (openai, deepseek, groq, openrouter, custom)
   - **Активна**: установите чекбокс, если модель активна

### Отправка запроса

1. Перейдите на вкладку "Запросы"
2. Введите промт в текстовое поле или выберите сохраненный промт из списка
3. (Опционально) Добавьте теги
4. Нажмите "Отправить"
5. Дождитесь получения ответов от всех активных моделей
6. Просмотрите результаты в таблице
7. Отметьте нужные результаты чекбоксами
8. Нажмите "Сохранить выбранные" для сохранения в базу данных

### Просмотр истории

1. Перейдите на вкладку "История"
2. Просмотрите все сохраненные результаты
3. Используйте поиск для фильтрации результатов
4. Двойной клик на строке открывает детальную информацию
5. Вы можете удалить или экспортировать результаты

### Настройки

1. Перейдите на вкладку "Настройки"
2. Настройте таймаут запросов и другие параметры
3. Сохраните изменения
