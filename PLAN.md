# План реализации программы ChatList

## Этап 1: Настройка окружения и структуры проекта

1.1. Обновить `requirements.txt`:
- Добавить библиотеки для работы с БД: `sqlite3` (встроенная)
- Добавить библиотеку для HTTP-запросов: `httpx` (или `requests`)
- Добавить библиотеку для работы с переменными окружения: `python-dotenv`

1.2. Создать структуру проекта:
```
ChatList/
├── main.py          # Главный файл с интерфейсом
├── db.py            # Модуль для работы с SQLite
├── models.py        # Логика работы с моделями нейросетей
├── network.py       # Модуль для отправки запросов к API
├── .env.example     # Пример файла с переменными окружения
├── .env             # Файл с API-ключами (в .gitignore)
└── requirements.txt
```

1.3. Создать файл `.env.example` с примером структуры переменных окружения

## Этап 2: Разработка модуля базы данных (db.py)

2.1. Создать класс `Database` с методами:
- `__init__()` - инициализация подключения к БД
- `init_db()` - создание всех таблиц при первом запуске
- Методы для работы с таблицей `prompts`:
  - `add_prompt(date, prompt, tags)`
  - `get_all_prompts()`
  - `get_prompt_by_id(id)`
  - `search_prompts(query)`
- Методы для работы с таблицей `models`:
  - `add_model(name, api_url, api_id, is_active)`
  - `get_active_models()`
  - `get_all_models()`
  - `update_model_status(id, is_active)`
  - `update_model(id, **kwargs)`
- Методы для работы с таблицей `results`:
  - `save_result(prompt_id, model_name, response_text)`
  - `get_all_results()`
  - `get_results_by_prompt_id(prompt_id)`
  - `search_results(query)`
- Методы для работы с таблицей `settings`:
  - `get_setting(key)`
  - `set_setting(key, value)`

2.2. Реализовать создание всех таблиц при первом запуске
