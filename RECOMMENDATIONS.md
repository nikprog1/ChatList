# Рекомендации по работе с повторяющимися запросами

## Как выбрать промты без сохраненных результатов

### Метод 1: Использование фильтра в интерфейсе

1. **Откройте вкладку "Запросы"** в главном окне приложения
2. **Нажмите кнопку "Без результатов"** рядом с выпадающим списком сохраненных промтов
3. В списке отобразятся только промты, которые не имеют связанных сохраненных результатов
4. Эти промты помечены символом ⚠ и текстом "(без результатов)"
5. Вы можете безопасно удалить эти промты, так как они не связаны с сохраненными результатами

### Метод 2: Просмотр истории сохраненных результатов

1. **Откройте вкладку "История"**
2. В таблице истории теперь отображаются два ID:
   - **ID результата** (колонка "ID результата") - уникальный идентификатор сохраненного результата
   - **ID запроса** (колонка "ID запроса") - идентификатор промта, связанного с этим результатом
3. Если в колонке "ID запроса" указано "(Удален)" серым цветом, это означает, что промт был удален, но результат остался в истории

### Метод 3: Использование SQL запроса (для продвинутых пользователей)

Если вы хотите использовать базу данных напрямую, можно выполнить следующий SQL запрос:

```sql
SELECT p.* 
FROM prompts p
LEFT JOIN results r ON p.id = r.prompt_id
WHERE r.id IS NULL
ORDER BY p.date DESC;
```

Этот запрос вернет все промты, которые не имеют связанных сохраненных результатов.

## Зачем это нужно?

- **Очистка базы данных**: Удаление неиспользуемых промтов помогает поддерживать базу данных в чистом состоянии
- **Экономия места**: Меньше записей = быстрее работает приложение
- **Улучшение производительности**: Меньше данных для поиска и фильтрации
- **Организация**: Легче найти нужные промты, когда нет "мусорных" записей

## Рекомендации

1. **Регулярная очистка**: Рекомендуется периодически проверять и удалять промты без результатов
2. **Перед удалением**: Убедитесь, что вы действительно не хотите сохранить результаты для этих промтов
3. **Резервное копирование**: Перед массовым удалением рекомендуется сделать резервную копию базы данных

## Дополнительная информация

- Промты, которые были использованы для отправки запросов, но результаты не были сохранены, также будут показаны в списке "Без результатов"
- Удаление промта с каскадным удалением (ON DELETE CASCADE) автоматически удалит все связанные результаты
- Если вы хотите сохранить результаты, но удалить промт, сначала экспортируйте результаты в файл
