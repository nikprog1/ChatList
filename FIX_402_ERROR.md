# Исправление ошибки 402 OpenRouter API

## Проблема

При использовании OpenRouter API возникала ошибка 402:
```
HTTP ошибка 402: Недостаточно кредитов или слишком много токенов
```

## Причина

OpenRouter API имеет ограничения на количество токенов, которые можно запросить в одном запросе. По умолчанию API запрашивает большое количество токенов (7168), но бесплатные аккаунты обычно могут позволить себе только ~5000 токенов.

## Решение

1. **Добавлен параметр `max_tokens` в запросы**
   - Теперь все запросы к OpenRouter API включают параметр `max_tokens`
   - По умолчанию установлено значение **2048** (безопасно для бесплатных аккаунтов)

2. **Добавлена настройка в интерфейс**
   - Перейдите на вкладку "Настройки"
   - Найдите поле "Макс. токенов в ответе"
   - Установите желаемое значение (рекомендуется 2048 для бесплатных аккаунтов)
   - Нажмите "Сохранить"

3. **Улучшена обработка ошибок**
   - Ошибка 402 теперь отображается с понятным сообщением
   - Предлагаются конкретные действия для решения проблемы

## Рекомендации

- **Бесплатные аккаунты**: используйте `max_tokens = 2048` или меньше
- **Платные аккаунты**: можете увеличить до 4096 или больше, в зависимости от вашего лимита
- **Проверка баланса**: если ошибка продолжается, проверьте баланс на https://openrouter.ai/settings/credits

## Изменения в коде

- `network.py`: добавлен параметр `max_tokens` во все провайдеры
- `db.py`: добавлена настройка `max_tokens` в базу данных
- `main.py`: добавлен интерфейс для настройки `max_tokens` и улучшено отображение ошибок

## Как использовать

1. Запустите приложение
2. Перейдите на вкладку "Настройки"
3. Установите "Макс. токенов в ответе" на 2048 (или меньше, если ошибка продолжается)
4. Нажмите "Сохранить"
5. Попробуйте отправить запрос снова

Если ошибка 402 все еще возникает, попробуйте:
- Уменьшить `max_tokens` до 1024 или 512
- Проверить баланс на OpenRouter
- Убедиться, что промт не слишком длинный (это также влияет на количество токенов)
