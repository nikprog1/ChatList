## Автоматическое обновление

При инициализации базы данных (`init_db()` или при первом запуске приложения) автоматически:

1. Обновляются существующие модели с неправильными названиями
2. Добавляются новые модели, если их ещё нет
3. Избегаются дубликаты (если модель с новым названием уже существует, старая удаляется)

Если какая-то модель не работает:

## Рекомендации

1. **Периодически проверяйте модели**: Список доступных моделей в OpenRouter может изменяться
2. **Следите за ошибками**: Если модель постоянно возвращает ошибку 404 или 400, проверьте актуальное название
3. **Обновляйте через интерфейс**: Используйте вкладку "Модели" для управления моделями вручную
4. **Деактивируйте неработающие модели**: Вместо удаления можно просто деактивировать модель (снять чекбокс "Активна")
