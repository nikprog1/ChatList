🤖 ChatList

Сравнивайте ответы от различных AI моделей в одном приложении

Версия 1.0.0

🚀 Множественные модели

Отправляйте один промт в несколько AI моделей одновременно и сравнивайте результаты в удобной таблице.

💾 Управление промтами

Сохраняйте часто используемые промты и быстро выбирайте их из списка. Организуйте работу с тегами.

📊 История результатов

Просматривайте все сохраненные результаты, фильтруйте по дате и модели, экспортируйте данные.

🔒 Безопасность

API ключи хранятся локально в зашифрованной базе данных SQLite. Ваши данные остаются конфиденциальными.

🎨 Настраиваемый интерфейс

Выбирайте между светлой и темной темой, настраивайте размер шрифта для комфортной работы.

✨ AI-ассистент

Используйте встроенный AI-ассистент для улучшения ваших промтов и получения лучших результатов.

📋 Системные требования

  • Windows 10 или новее (64-bit)
  • ~50 МБ свободного места на диске
  • Подключение к интернету
  • API ключ от OpenRouter или другой поддерживаемой платформы

🚀 Быстрый старт

  1. Скачайте и запустите ChatList-1.0.0.exe
  2. Откройте вкладку "Модели"
  3. Выберите модель и нажмите "Редактировать"
  4. Введите ваш API ключ в поле "API ключ"
  5. Активируйте модель, установив чекбокс "Модель активна"
  6. Сохраните изменения и начните использовать!
