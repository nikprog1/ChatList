🚀 Быстрый старт

  1. Скачайте и запустите ChatList-1.0.0.exe

  3. Выберите модель и нажмите "Редактировать"
  4. Введите ваш API ключ
  5. Активируйте модель и сохраните
  6. Начните использовать!
