## Технологии тестирования

### Использованные библиотеки:
- `pytest` - основной фреймворк
- `pytest-qt` - для тестирования PyQt5 (установлен, но не использован)
- `pytest-asyncio` - для асинхронных тестов
- `pytest-cov` - для проверки покрытия кода
- `pytest-mock` - для создания моков
- `respx` - для моков HTTP запросов (httpx)
- `faker` - для генерации тестовых данных (не использован, но установлен)

### Моки и фикстуры:
- Временная БД для каждого теста (изоляция)
- Моки API-ключей через патчинг методов
- Моки HTTP запросов через respx
- Готовые тестовые данные через фикстуры

## Запуск тестов

### Все тесты:
```powershell
pytest tests/ -v
```

### Только UNIT тесты:
```powershell
pytest tests/unit/ -v -m unit
```

### Только E2E тесты:
```powershell
pytest tests/e2e/ -v -m e2e
```

### С покрытием кода:
```powershell
pytest tests/ --cov=. --cov-report=html
Start-Process htmlcov/index.html
```

### Конкретный файл:
```powershell
pytest tests/unit/test_db.py -v
```
