# ChatList v1.0.0

## 🎉 Первый стабильный релиз!

ChatList — приложение для сравнения ответов от различных AI моделей.

## ✨ Что нового

- Отправка промтов в несколько AI моделей одновременно
- Управление моделями и промтами
- История результатов с фильтрацией
- Безопасное хранение API ключей
- Настраиваемый интерфейс (темы, размер шрифта)
- Просмотр ответов в Markdown

## 📥 Установка

### Windows

1. Скачайте `ChatList-1.0.0.exe`
2. Запустите файл (не требует установки)
3. Добавьте API ключи через вкладку "Модели"

### Установщик

1. Скачайте `ChatList-Setup-1.0.0.exe`
2. Запустите установщик
3. Следуйте инструкциям

## 🔑 Настройка API ключей

1. Откройте вкладку "Модели"
2. Выберите модель → "Редактировать"
3. Введите API ключ
4. Активируйте модель
5. Сохраните

**Примечание**: API ключи хранятся локально в SQLite БД.

## 📋 Системные требования

- Windows 10 или новее
- ~50 МБ свободного места
- Подключение к интернету

## 🐛 Известные проблемы

- Только Windows (Linux/macOS не поддерживаются)
