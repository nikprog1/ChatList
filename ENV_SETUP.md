# Инструкция по настройке файла .env.local

## Проблема: "У активных моделей не найдены API-ключи"

Если вы видите это предупреждение, значит файл `.env.local` либо не существует, либо не содержит правильный формат переменной `OPENROUTER_API_KEY`.

## Решение

### 1. Создайте или откройте файл `.env.local`

```powershell
notepad .env.local
```

### 2. Добавьте строку с вашим API-ключом OpenRouter

Файл должен содержать **точно** такую строку (без пробелов, кавычек, комментариев):

```
OPENROUTER_API_KEY=sk-or-v1-ваш_реальный_ключ_здесь
```

**Пример правильного формата:**
```
OPENROUTER_API_KEY=sk-or-v1-abc123def456ghi789jkl012mno345pqr678stu901vwx234yz
```

### 3. Проверьте формат

✅ **Правильно:**
```
OPENROUTER_API_KEY=sk-or-v1-ваш_ключ
```

❌ **Неправильно:**
```
OPENROUTER_API_KEY = sk-or-v1-ваш_ключ  (пробелы вокруг =)
OPENROUTER_API_KEY="sk-or-v1-ваш_ключ"  (кавычки)
OPENROUTER_API_KEY=sk-or-v1-ваш_ключ  # комментарий  (комментарий в строке)
OPENROUTER_API_KEY = "sk-or-v1-ваш_ключ"  # все ошибки сразу
```

### 4. Сохраните файл и перезапустите приложение

**Важно:** После изменения `.env.local` обязательно **перезапустите** приложение:

```powershell
# Закройте приложение (если запущено)
# Затем запустите заново:
python main.py
```

### 5. Проверка

Выполните проверку загрузки:

```powershell
python -c "from dotenv import load_dotenv; import os; load_dotenv('.env.local'); key = os.getenv('OPENROUTER_API_KEY'); print('OK - ключ найден!' if key and len(key) > 10 else 'ERROR - ключ не найден или слишком короткий')"
```

Если выводит "OK - ключ найден!", значит всё настроено правильно.

## Где взять API-ключ OpenRouter?

1. Зайдите на https://openrouter.ai/
2. Зарегистрируйтесь или войдите
3. Перейдите в раздел "Keys" (Ключи)
4. Создайте новый ключ
5. Скопируйте ключ (он начинается с `sk-or-v1-`)

## Где хранить ключи: .env.local vs .env

### ✅ Рекомендуется: `.env.local`

**Плюсы:**
- Автоматически игнорируется git (добавлен в `.gitignore`)
- Безопасно для локальной разработки
- Не конфликтует с настройками команды
- Имеет приоритет над `.env`

**Использование:**
- Для личных локальных ключей
- Для тестирования
- Для разработки

### Альтернатива: `.env`

**Используйте если:**
- Нужны общие настройки команды
- Хотите добавить пример в репозиторий (`.env.example`)

**Приоритет загрузки:**
1. `.env.local` (если существует) ← **приоритет**
2. `.env` (если `.env.local` нет)
3. Системные переменные окружения

## Устранение неполадок

### Проблема: "Ключ всё ещё не найден"

1. **Проверьте имя переменной:**
   - Должно быть точно `OPENROUTER_API_KEY` (заглавными буквами)
   - Без пробелов до и после имени

2. **Проверьте формат файла:**
   - Сохраните файл в кодировке UTF-8
   - Убедитесь, что нет скрытых символов

3. **Проверьте путь:**
   - Файл `.env.local` должен быть в корне проекта (`C:\Work\ChatList\.env.local`)
   - Рядом с файлом `main.py`

4. **Перезапустите приложение:**
   - Закройте полностью
   - Запустите заново

5. **Проверьте через Python:**
```powershell
python -c "from dotenv import load_dotenv; import os; load_dotenv('.env.local', override=True); print('Key:', os.getenv('OPENROUTER_API_KEY')[:20] if os.getenv('OPENROUTER_API_KEY') else 'NOT FOUND')"
```

## Пример правильного файла .env.local
