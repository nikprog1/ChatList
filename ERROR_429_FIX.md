# Исправление ошибки 429 (Too Many Requests)

## Проблема

При отправке слишком большого количества запросов к OpenRouter API возникает ошибка 429 (Too Many Requests):
```
HTTP ошибка 429: Provider returned error
```

Эта ошибка означает, что превышен лимит количества запросов в единицу времени.

## Решение

Добавлена улучшенная обработка ошибки 429 с понятными сообщениями и рекомендациями.

### Что было сделано:

1. **Улучшена обработка ошибки 429 в `network.py`**:
   - Добавлена специальная обработка для статуса 429 перед вызовом `raise_for_status()`
   - Извлекается информация о времени ожидания из заголовка `Retry-After` (если есть)
   - Формируется понятное сообщение об ошибке с рекомендациями

2. **Улучшено отображение ошибки в интерфейсе**:
   - Ошибка 429 корректно отображается в таблице результатов
   - Показывается понятное сообщение с рекомендациями

### Сообщение об ошибке 429:

Когда возникает ошибка 429, пользователь видит:

```
Слишком много запросов (429): Превышен лимит запросов к модели 'model_name'.

Решение: Подождите несколько секунд перед повторным запросом или уменьшите количество одновременных запросов.
Проверьте лимиты на https://openrouter.ai/settings

Детали: [детальная информация об ошибке]
```

Если сервер предоставляет заголовок `Retry-After`, отображается точное время ожидания:

```
Слишком много запросов (429): Превышен лимит запросов к модели 'model_name'.
Подождите 60 секунд перед следующим запросом.

Решение: Уменьшите количество одновременных запросов или сделайте паузу между запросами.
```

## Рекомендации по избежанию ошибки 429

1. **Уменьшите количество одновременных запросов**:
   - Откройте вкладку "Настройки"
   - Уменьшите значение "Макс. одновременных запросов" (например, с 5 до 2-3)
   - Сохраните настройки

2. **Используйте меньше моделей одновременно**:
   - Деактивируйте ненужные модели (снимите чекбокс "Активна")
   - Оставляйте активными только модели, которые действительно нужны для тестирования

3. **Делайте паузы между запросами**:
   - После получения ошибки 429 подождите несколько секунд перед повторным запросом
   - Если в сообщении об ошибке указано время ожидания (`Retry-After`), подождите указанное время

4. **Проверьте лимиты вашего аккаунта**:
   - Откройте https://openrouter.ai/settings
   - Проверьте лимиты вашего тарифного плана
   - Для бесплатных аккаунтов лимиты обычно ниже

5. **Рассмотрите возможность обновления тарифа**:
   - Если вы часто получаете ошибку 429, возможно, стоит рассмотреть платный тариф
   - Платные тарифы имеют более высокие лимиты на количество запросов

## Технические детали

### Изменения в коде:

**`network.py` - `OpenRouterProvider.send_request()`**:
```python
# Обработка ошибки 429 (Too Many Requests - слишком много запросов)
if response.status_code == 429:
    try:
        error_data = response.json()
        error_msg = error_data.get("error", {}).get("message", "")
        
        # Проверяем, есть ли информация о времени ожидания
        retry_after = response.headers.get("Retry-After", "")
        if retry_after:
            error = f"Слишком много запросов (429): ... Подождите {retry_after} секунд ..."
        else:
            error = f"Слишком много запросов (429): ... Подождите несколько секунд ..."
    except:
        error = f"HTTP ошибка 429: Слишком много запросов ..."
    self.log_request(model, prompt, error=error)
    return "", error
```

**`main.py` - `ResultsTableWidget.set_results()` и `add_result()`**:
- Добавлена обработка ошибки 429 для корректного отображения в интерфейсе
