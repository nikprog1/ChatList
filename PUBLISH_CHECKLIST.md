# Чеклист публикации ChatList

Используйте этот чеклист перед каждым релизом.

## Подготовка

- [ ] Все изменения закоммичены в репозиторий
- [ ] Версия обновлена в `version.py`
- [ ] `CHANGELOG.md` обновлен с описанием изменений
- [ ] README.md актуален (если были изменения в функционале)
- [ ] Код протестирован локально

## Сборка

- [ ] EXE файл собран успешно (`pyinstaller MinimalProgram.spec --clean --noconfirm`)
- [ ] EXE файл протестирован на чистой системе (если возможно)
- [ ] Установщик создан (если используется Inno Setup)
- [ ] Размер файлов разумный (проверить размер EXE)

## GitHub Release

- [ ] Тег версии создан (`git tag -a v1.0.0 -m "Release version 1.0.0"`)
- [ ] Тег отправлен на GitHub (`git push origin v1.0.0`)
- [ ] Release создан на GitHub с правильным описанием
- [ ] Файлы загружены в Release:
  - [ ] ChatList-X.X.X.exe
  - [ ] ChatList-Setup-X.X.X.exe (если есть)
- [ ] Release опубликован (не в draft)

## GitHub Pages

- [ ] `docs/index.html` обновлен (версия, ссылки)
- [ ] Изменения закоммичены и запушены
