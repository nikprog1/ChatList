# ChatList v1.0.0

## 🎉 Первый стабильный релиз!

ChatList — это приложение для сравнения ответов от различных AI моделей. Отправляйте один промт в несколько нейросетей одновременно и сравнивайте результаты в удобной таблице.

## ✨ Основные возможности

- **Множественные AI модели**: Поддержка различных моделей через OpenRouter API
- **Сравнение ответов**: Параллельная отправка запросов и сравнение результатов
- **Управление промтами**: Сохранение и повторное использование промтов
- **История результатов**: Просмотр и фильтрация сохраненных результатов
- **Безопасность**: Локальное хранение API ключей в зашифрованной базе данных
- **Настраиваемый интерфейс**: Темы и размер шрифта
- **Markdown просмотр**: Форматированный просмотр ответов нейросетей
- **AI-ассистент**: Автоматическое улучшение промтов

## 📥 Установка

### Windows

1. Скачайте `ChatList-1.0.0.exe` из раздела Assets ниже
2. Запустите файл (не требует установки)
3. При первом запуске добавьте API ключи через вкладку "Модели"

### Альтернативный вариант (установщик)

1. Скачайте `ChatList-Setup-1.0.0.exe`
2. Запустите установщик и следуйте инструкциям
3. После установки запустите ChatList из меню Пуск

## 🔑 Настройка API ключей

1. Откройте вкладку "Модели"
2. Выберите модель и нажмите "Редактировать"
3. Введите ваш API ключ в поле "API ключ"
4. Активируйте модель, установив чекбокс "Модель активна"
5. Сохраните изменения

**Примечание**: API ключи хранятся локально в базе данных SQLite и не передаются третьим лицам.

## 📋 Системные требования

- Windows 10 или новее
- ~50 МБ свободного места на диске
- Подключение к интернету

## 🐛 Известные проблемы

- Нет поддержки Linux/macOS (только Windows)
- Требуется ручная настройка API ключей
