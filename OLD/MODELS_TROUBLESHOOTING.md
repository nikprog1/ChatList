# Устранение проблем с моделями OpenRouter

## Проблемы и решения

### Ошибка 404: "No endpoints found for model_name"

**Причина**: Модель не найдена в OpenRouter. Возможные причины:
- Модель устарела и была удалена из OpenRouter
- Название модели написано неправильно
- Модель требует специального доступа или оплаты

**Решение**:
1. Проверьте доступные модели на https://openrouter.ai/models
2. Найдите правильное название модели
3. Удалите неработающую модель через интерфейс управления моделями
4. Добавьте модель с правильным названием

**Пример**:
- Неправильно: `allenai/molmo-2-8b` (может не существовать)
- Правильно: Проверьте актуальный список на https://openrouter.ai/models

### Ошибка 400: "model_name is not a valid model ID"

**Причина**: Название модели неверное или модель не существует в OpenRouter.

**Решение**:
1. Проверьте правильность написания названия модели
2. Убедитесь, что модель доступна в OpenRouter
3. Проверьте список моделей на https://openrouter.ai/models
4. Обновите название модели или удалите её

**Пример**:
- Неправильно: `google/gemma-3-27b` (может быть неправильное название)
- Правильно: Проверьте актуальное название на https://openrouter.ai/models
  - Возможно: `google/gemma-2-27b-it` или другое название

### Ошибка 402: "Недостаточно кредитов"

**Причина**: Превышен лимит токенов или недостаточно средств на балансе.

**Решение**:
1. Уменьшите `max_tokens` в настройках (рекомендуется 2048 для бесплатных аккаунтов)
2. Проверьте баланс на https://openrouter.ai/settings/credits
3. Пополните баланс, если необходимо

### Ошибка 429: "Слишком много запросов" (Too Many Requests)

**Причина**: Превышен лимит количества запросов в единицу времени. Это происходит, когда отправляется слишком много запросов одновременно или слишком часто.

**Решение**:
1. Уменьшите количество одновременных запросов в настройках (вкладка "Настройки" → "Макс. одновременных запросов")
2. Деактивируйте ненужные модели, оставьте активными только те, которые нужны
3. Подождите несколько секунд перед повторным запросом (если в сообщении указано время ожидания - подождите это время)
4. Проверьте лимиты вашего аккаунта на https://openrouter.ai/settings
5. Для бесплатных аккаунтов лимиты обычно ниже - рассмотрите возможность обновления тарифа

**Детали**: Ошибка 429 теперь обрабатывается с понятными сообщениями. Если сервер предоставляет заголовок `Retry-After`, отображается точное время ожидания перед следующим запросом.

## Как обновить список моделей

1. Откройте приложение
2. Перейдите на вкладку "Модели"
3. Найдите неработающую модель
4. Нажмите "Редактировать" или "Удалить"
5. Если редактируете - исправьте название модели
6. Если удаляете - удалите модель и добавьте новую с правильным названием

## Проверка доступных моделей через API

Вы можете проверить доступные модели через API OpenRouter:

```bash
curl https://openrouter.ai/api/v1/models -H "Authorization: Bearer YOUR_API_KEY"
```

Или используйте веб-интерфейс: https://openrouter.ai/models

## Рекомендации

1. **Регулярно проверяйте модели**: Список доступных моделей в OpenRouter меняется
2. **Используйте проверенные модели**: Проверяйте модели на работоспособность перед массовым использованием
3. **Удаляйте неработающие модели**: Неактивные модели можно деактивировать (снять чекбокс "Активна")
4. **Проверяйте баланс**: Регулярно проверяйте баланс на OpenRouter, чтобы избежать ошибок 402
