## Установка зависимостей

### Базовые библиотеки для тестирования

```powershell
# Установка pytest и необходимых плагинов
pip install pytest>=7.4.0
pip install pytest-qt>=4.2.0          # Для тестирования PyQt5 приложений
pip install pytest-asyncio>=0.21.0     # Для асинхронных тестов
pip install pytest-cov>=4.1.0          # Для проверки покрытия кода
pip install pytest-mock>=3.11.1        # Для создания моков
pip install pytest-timeout>=2.1.0      # Для ограничения времени выполнения тестов
```

### Дополнительные библиотеки для моков и фикстур

```powershell
pip install responses>=0.23.1          # Для моков HTTP запросов (альтернатива: respx)
pip install respx>=0.20.0              # Альтернативная библиотека для моков httpx (рекомендуется)
pip install faker>=19.0.0              # Для генерации тестовых данных
pip install freezegun>=1.2.2           # Для моков времени и дат
```

### Добавление в requirements.txt

Создать файл `requirements-test.txt`:
```txt
# Тестирование
pytest>=7.4.0
pytest-qt>=4.2.0
pytest-asyncio>=0.21.0
pytest-cov>=4.1.0
pytest-mock>=3.11.1
pytest-timeout>=2.1.0
respx>=0.20.0
faker>=19.0.0
freezegun>=1.2.2
```

### Или установить все сразу:
```powershell
pip install -r requirements-test.txt
```

## Запуск тестов

### Запуск всех тестов:

```powershell
# Все тесты с покрытием
pytest

pytest tests/unit/ -m unit

# Только E2E тесты
pytest tests/e2e/ -m e2e

pytest -v

# Тесты конкретной функции
```

## Дополнительные рекомендации

1. **Использование моков**: Все сетевые запросы должны быть замоканы с помощью `respx` или `responses`
2. **Изоляция тестов**: Каждый тест должен работать с изолированной БД (tempfile)
3. **Тестовые данные**: Использовать `faker` для генерации реалистичных тестовых данных
4. **Очистка**: После каждого теста очищать тестовые данные
5. **Асинхронность**: Для асинхронных тестов использовать `pytest-asyncio`
6. **PyQt5 тестирование**: Использовать `pytest-qt` для тестирования GUI компонентов
7. **Таймауты**: Устанавливать таймауты для предотвращения зависания тестов
