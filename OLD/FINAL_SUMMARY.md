## Команды для работы с проектом

### Запуск приложения:
```powershell
python main.py
```

### Запуск тестов:
```powershell
# Все тесты
pytest tests/ -v

# Только UNIT
pytest tests/unit/ -v -m unit

# Только E2E
pytest tests/e2e/ -v -m e2e

# С покрытием
pytest tests/ --cov=. --cov-report=html
```

### Сборка exe-файла:
```powershell
pyinstaller MinimalProgram.spec
```
