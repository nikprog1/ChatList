## Этап 17: Реализация функции "AI-ассистент для улучшения промтов"

17.1. Создать модуль `prompt_improver.py`:
- Класс `PromptImprover` для работы с улучшением промтов
- Метод `improve_prompt(prompt: str, model: Model) -> Dict[str, Any]`:
  - Принимает исходный промт и модель для улучшения
  - Формирует системный промт для AI-ассистента:
    - Запрос на улучшение исходного промта
    - Запрос на создание 2-3 вариантов переформулировки
    - Запрос на адаптацию под разные типы задач (код, анализ, креатив)
  - Использует существующий `OpenRouterProvider` для отправки запроса
  - Парсит ответ и возвращает структурированные данные:
    ```python
    {
        'improved': str,           # Улучшенная версия
        'alternatives': List[str],  # 2-3 варианта переформулировки
        'adaptations': {
            'code': str,           # Адаптация для задач программирования
            'analysis': str,       # Адаптация для аналитических задач
            'creative': str        # Адаптация для креативных задач
        }
    }
    ```
- Метод `format_improvement_request(prompt: str) -> str`:
  - Формирует структурированный запрос для AI-модели
  - Использует шаблон с четкими инструкциями
  - Запрашивает ответ в формате, удобном для парсинга (JSON или маркированный список)

  - **Альтернативные варианты**: QListWidget или QComboBox с вариантами переформулировки
  - **Адаптации для разных задач**: QTabWidget с вкладками:

    - "Анализ" - адаптация для аналитических задач
