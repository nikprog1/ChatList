# План упаковки ChatList в EXE файл

## Цель

Упаковать приложение ChatList в единый исполняемый файл (EXE) с сохранением всего функционала и данных:
- Все функции приложения работают корректно
- База данных создается и используется рядом с EXE файлом
- Файлы окружения (.env, .env.local) читаются рядом с EXE файлом
- Иконка приложения отображается корректно
- Все модули включены в сборку

## Этапы реализации

### 1. Подготовка к упаковке

#### 1.1. Проверка зависимостей
- [ ] Убедиться, что все зависимости установлены:
  ```powershell
  pip install -r requirements.txt
  ```
- [ ] Убедиться, что PyInstaller установлен:
  ```powershell
  pip install pyinstaller>=6.15.0
  ```

#### 1.2. Проверка работоспособности приложения
- [ ] Запустить приложение из исходников:
  ```powershell
  python main.py
  ```
- [ ] Проверить все основные функции:
  - Создание/удаление промтов
  - Управление моделями
  - Отправка запросов к API
  - Сохранение результатов
  - Просмотр истории
  - Настройки (тема, размер шрифта)
  - Улучшение промтов
  - О программе

#### 1.3. Проверка ресурсов
- [ ] Убедиться, что файл `app.ico` существует
- [ ] Проверить, что все необходимые файлы на месте:
  - `main.py`
  - `db.py`
  - `models.py`
  - `network.py`
  - `models_dialog.py`
  - `history_widget.py`
  - `prompt_improver.py`
  - `app.ico`

## Примечания

1. **База данных:** Создается автоматически рядом с EXE файлом при первом запуске. Все данные сохраняются в файле `chatlist.db`.

2. **Файлы окружения:** Пользователь должен создать файл `.env.local` или `.env` рядом с EXE файлом с API-ключами. Файлы `.env` НЕ включаются в EXE для безопасности.

3. **Иконка:** Файл `app.ico` должен быть включен в сборку через параметр `datas` в .spec файле.

4. **Пути:** Все пути должны определяться относительно директории EXE файла, а не временной директории PyInstaller (`_MEIPASS`).

5. **Тестирование:** Обязательно протестировать EXE файл как на локальной машине, так и на чистой системе Windows без установленного Python.
