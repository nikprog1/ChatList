# Changelog

Все значимые изменения в проекте ChatList будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2025-01-XX

### Добавлено
- Первый стабильный релиз ChatList
- Графический интерфейс на PyQt5 для сравнения ответов нейросетей
- Поддержка множества AI моделей через OpenRouter API
- Управление моделями: добавление, редактирование, удаление, активация/деактивация
- Сохранение и управление промтами
- История сохраненных результатов с возможностью фильтрации
- Экспорт результатов в различные форматы
- Просмотр ответов в форматированном Markdown
- AI-ассистент для улучшения промтов
- Настройки интерфейса: темы (светлая/темная) и размер шрифта
- Безопасное хранение API ключей в локальной базе данных SQLite
- Поддержка переменных окружения для API ключей
- Автоматическая миграция базы данных при обновлении
- Иконка приложения
- Меню "Справка" с информацией о программе

### Технические детали
- База данных SQLite для хранения промтов, моделей, результатов и настроек
- Асинхронная обработка запросов с использованием httpx и asyncio
- Кэширование данных моделей для оптимизации производительности
- Обработка ошибок API (400, 402, 404, 429)
- Поддержка Windows 10+

### Известные ограничения
- Требуется подключение к интернету для работы с API
- Поддержка только Windows (EXE файл)
