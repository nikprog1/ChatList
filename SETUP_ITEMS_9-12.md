## 🚀 Что нужно сделать

### Шаг 1: Настройте репозиторий

#### Вариант A: Автоматическая настройка (рекомендуется)

1. Откройте `setup_repo.py`
2. Обновите значения:
   ```python
   REPO_USERNAME = "ваш_github_username"
   REPO_NAME = "название_репозитория"
   VERSION = "1.0.0"  # Должна совпадать с version.py
   ```
3. Запустите:
   ```powershell
   python setup_repo.py
   ```

#### Вариант B: Ручная настройка

Замените `yourusername/chatlist` на ваш репозиторий в следующих файлах:

**`docs/index.html`** (3 места):
- Строка ~303: Ссылка на скачивание EXE
- Строка ~306: Ссылка на скачивание установщика
- Строка ~338: Ссылка на CHANGELOG.md
- Строки ~344-346: Ссылки в футере

**`docs/index-simple.html`** (3 места):
- Строка ~143: Ссылка на скачивание EXE
- Строка ~146: Ссылка на скачивание установщика
- Строки ~179-181: Ссылки в футере

**Формат:**
```
https://github.com/yourusername/chatlist
↓
https://github.com/ВАШ_USERNAME/ВАШ_РЕПОЗИТОРИЙ
```

### Шаг 2: Настройте GitHub Pages

1. Перейдите в ваш репозиторий на GitHub
2. Settings → Pages
3. Source: "Deploy from a branch"
4. Branch: `main` (или `master`)
5. Folder: `/docs`
6. Save

**Результат:** Через 2-5 минут сайт будет доступен по адресу:
```
https://ВАШ_USERNAME.github.io/ВАШ_РЕПОЗИТОРИЙ/
```

### Шаг 3: Проверьте GitHub Actions

GitHub Actions уже настроены и готовы к работе:

- **Автоматическая сборка и релиз:**
  - При создании тега `v1.0.0` автоматически:
    1. Соберется EXE файл
    2. Создастся Release на GitHub
    3. Загрузится EXE в Release

- **Автоматическое развертывание Pages:**
  - При изменении файлов в `docs/` автоматически обновится сайт

**Для тестирования:**
```powershell
# Создайте тег (это запустит автоматическую сборку)
git tag -a v1.0.0 -m "Release version 1.0.0"
git push origin v1.0.0
```
